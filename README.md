# Ssokly

학교 공문을 읽고 교사가 실행할 업무와 일정을 정리하는 Windows 데스크톱 앱입니다.
만든 사람: docsusil · Pull tasks out of documents.

문서 기준일: 2026-09-17. 이 문서는 현재 작업 트리의 동작을 설명합니다. GitHub 배포 완료를 뜻하지 않습니다.

- [작업 상태·변경 기록](STATUS.md): 완료 내용, 결정 사항, 남은 작업, 작업별 이력
- [검증 기록](VALIDATION.md): 시험 결과, 재실행 방법, 아직 확인하지 못한 범위
- [개발 작업 지침](AGENTS.md): 변경 후 문서 갱신 규칙

## 핵심 사용 흐름

화면 캡처 또는 파일 열기 → 원문 검수 → 요약·업무 초안 생성 → 필요한 할 일 선택 → 저장·완료 관리

OCR과 분석은 모두 `gpt-5-nano`로 자동 지정합니다. 담당 역할·모델 선택 메뉴는 없습니다. 공문에 나온 담당자 전체의 업무를 정리하고 사용자가 필요한 항목만 선택합니다. Windows 로컬 OCR은 비교용 서비스로 남아 있지만 기본 캡처 경로가 아닙니다. Windows AI TextRecognizer는 연동하지 않았습니다.

## 설치와 실행

Windows와 tkinter가 포함된 Python 환경이 필요합니다. 현재 검증 환경은 Python 3.12.10입니다. 다음 명령은 `main.py`와 `requirements.txt`가 있는 저장소 루트에서 PowerShell로 실행합니다.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

저장소 루트의 `.env.example`을 참고해 `.env`에 API 키를 설정합니다. 기존 `.env`가 있다면 키를 덮어쓰지 마세요.

```dotenv
OPENAI_API_KEY=your_api_key_here
OPENAI_OCR_DETAIL=high
OPENAI_IMAGE_MODEL=gpt-image-2.5-flare
```

`.env.example`의 `OPENAI_MODEL`, `OPENAI_OCR_MODEL`, `OPENAI_ANALYSIS_MODEL`은 이전 설정과의 호환을 위해 남아 있습니다. 현재 앱의 OCR·분석 모델을 바꾸지 않으며 기본 서비스도 nano를 사용합니다. 개발·비교 도구의 명시적 모델 인자는 별도입니다. 앱의 캡처 OCR은 `high` 상세도를 명시합니다. 이미지 생성 모델은 `OPENAI_IMAGE_MODEL` 설정을 읽습니다.

```powershell
.\.venv\Scripts\python.exe main.py
```

콘솔 없이 실행하려면 `.venv\Scripts\pythonw.exe main.py`를 사용합니다. 현재 노트북의 저장소 이름은 `autoedu`이므로 추가로 `cd Ssokly`를 실행할 필요가 없습니다.

## 원문 읽기와 검수

1. `화면 캡처`로 문서 영역을 드래그하거나 `첨부 파일 열기`를 사용합니다.
2. 캡처 원본은 로컬 보관함에 저장되고, 이미지 읽기는 OpenAI API를 사용합니다.
3. 원문을 원본과 대조해 날짜·담당·표를 검수합니다. 캡처함에서는 AI OCR 원문과 교사 검수본을 별도로 보관합니다.
4. `표 보기`로 행·열을 확인하고, 행을 선택해 잘린 셀의 전체 내용을 읽을 수 있습니다. 선택한 표는 TSV로 복사할 수 있습니다.

인식된 유효한 날짜는 **청록색**, `⟦불확실:…⟧`·`⟦판독불가⟧` 및 존재하지 않는 날짜는 **빨간 밑줄**로 표시합니다. 청록색은 OCR 정확도 보증이 아니며, 빨간 표시가 없다고 검수가 끝난 것은 아닙니다. 색상은 저장된 원문을 변경하지 않습니다.

### 파일별 처리

| 입력 | 처리 방식 |
| --- | --- |
| PNG/JPG/JPEG/BMP/WEBP | 이미지 OCR API |
| TXT/MD/CSV/TSV/JSON/XML/HTML | 로컬 텍스트 읽기 |
| HWPX | 로컬 XML 추출, 다열 표는 탭으로 보존 |
| PDF/DOC/DOCX/RTF/ODT/PPT/PPTX/XLS/XLSX | API 문서 읽기 경로 제공; 실제 호환성은 파일별 확인 필요 |
| 구형 HWP | 직접 읽기 미지원; HWPX/PDF로 변환하거나 캡처 |

HWPX 병합 셀은 `↳`로 이어지는 값을 표시합니다. 단일열 배치용 표는 문단으로, 중첩 표는 셀 안 텍스트로 펼칩니다. 원본 지면을 그대로 재현하는 뷰어는 아닙니다. 캡처 표는 모델에 빈 셀·열 제목·셀 위치 보존을 지시하지만 복잡한 표의 정확성을 보장하지는 않습니다.

캡처함은 검색, 미분류/업무 연결/전체/휴지통 필터, 여러 장 묶기와 현재 업무 추가를 지원합니다. 재OCR은 교사 검수본을 덮어쓰지 않으며 실패해도 직전 성공 원문을 유지합니다. 여러 장 OCR은 장마다 호출하고 최대 20장으로 제한합니다. 목록은 최근 250개를 먼저 표시합니다.

## 업무 결과와 내 할 일

검수한 원문에서 다음 양식을 선택합니다.

- `업무 일정·체크리스트`: 전체 담당자의 업무와 기한, 원문에서 직접 찾은 일정
- `교직원 메신저`: 교직원에게 전달할 안내 초안
- `학부모 메신저`: 학부모 대상 안내 초안
- `가정통신문 초안`: 가정통신문 구성의 안내 초안
- `원문 요약`: 핵심 요약과 확인 사항. 원문은 유지하지만 현재 결과 탭은 요약으로 교체됩니다.

날짜는 표기가 달라도 연·월·일·시간을 비교하고 원문의 시간과 `예정/까지`를 유지합니다. 원문에 없는 연도를 추측하거나 여러 기한 중 하나를 임의 선택하지 않습니다. AI가 업무를 놓쳐도 원문에서 찾은 일정은 일정 메모에 함께 표시합니다. 담당 여부와 행사일/제출기한 구분은 검수해야 합니다.

### 문맥·근거 검토 (2026-09-17)

AI는 원문 줄·표 셀 번호를 선택하고 앱이 해당 내용을 그대로 인용합니다. 업무 행동과 담당·기한·제출물·제출처는 서로 다른 위치의 근거를 연결할 수 있습니다. 학교 업무와 외부 기관 업무·참고 일정을 구분해 표시합니다. 이 분류와 문맥 연결은 AI 판단이므로 사람이 최종 확인해야 합니다.

근거 오류는 업무별 한 줄로 묶습니다. 제출물·제출처가 해당 없거나 기재되지 않았다면 빈 값을 경고로 바꾸지 않습니다. 담당이 비어 있으면 `원문 미기재`로 표시합니다. 검증을 통과하지 못한 항목은 `검수 대기 업무`에 표시하고 정상 체크리스트/내 할 일 선택에서 제외합니다. 중요한 오류를 숨기거나 자동 확정하는 방식은 아닙니다.

검증 실패 또는 확인 필요 항목이 있으면 같은 nano로 **최대 8개 항목을 1회 추가 재검토**합니다. 이미 분석한 원문을 다시 전송하며 추가 비용·시간이 발생합니다(추가 요청 30초 타임아웃, 자동 재시도 없음). 실패하면 1차 결과와 안내를 남기고 해당 실패 결과는 캐시하지 않습니다. 정상 항목은 다시 생성하지 않습니다.

문맥 검토를 위해 내부 분석 추론 설정을 `minimal`에서 `low`로 조정했습니다. 최초 분석이 이전보다 느릴 수 있으며 같은 원문의 캐시는 재사용합니다. 과거 경고가 많은 분석 캐시는 버전을 변경해 재사용하지 않습니다. 기존 원문이 정확하다면 앱 재시작 후 재분석만 하면 됩니다. 원문 자체가 잘못 읽혔다면 먼저 수정하거나 재OCR하세요.

`내 할 일로 담기`에서 필요한 체크리스트만 선택하고 `내 할 일 보기`에서 완료·다시 할 일로·삭제합니다. 추가 AI 호출은 없습니다. 원문과 결과가 변경됐거나 이전 버전 결과에 연결 정보가 없으면 먼저 재분석해야 합니다. 이미 담은 할 일은 원문 수정·재분석·업무 삭제에 따라 자동 변경되지 않습니다. 동일 원문·동일 항목의 재추가는 중복이나 완료 상태 초기화를 만들지 않습니다.

`업무로 저장` 후에는 편집 내용이 700ms 자동 저장됩니다. 업무 검색·진행중/완료 필터·재열기·부분 복사를 지원합니다. 처리 도중 편집하거나 업무를 이동하면 늦게 도착한 AI 결과가 편집 내용을 덮어쓰지 않도록 보호합니다.

업무 일정·교직원 안내·원문 요약은 같은 내부 분석 캐시를 재사용합니다. 학부모 메신저와 가정통신문은 각 양식별 별도 생성·캐시를 사용합니다. 원문·모델·검증 버전 등에 따라 캐시가 달라집니다. 내부 업무 분석은 완성된 행동 항목부터 미리 보여줍니다.

`실행안으로 업무 도식화 만들기`는 검수한 결과로 별도 이미지 생성을 요청합니다. 현재 코드의 기본 모델 식별자는 `gpt-image-2.5-flare`이며 API 계정 접근 권한에 따라 실행 가능 여부가 달라집니다. 비용 안내 후 생성하고 PNG로 저장할 수 있습니다. 이미지의 한글·날짜·화살표 관계도 검수하세요.

창은 컴팩트 모드, 항상 위, 투명도 조절을 지원하고 설정을 다음 실행에 복원합니다.

## 데이터 보관과 개인정보

기본 저장 위치는 `%LOCALAPPDATA%\Ssokly`입니다.

| 경로 | 내용 |
| --- | --- |
| `ssokly.db` | 업무 원문·실행안·상태·출처 |
| `capture_inbox\*.png` | 캡처 원본 |
| `capture_inbox\capture_inbox.sqlite3` | 캡처 OCR·검수본·연결·휴지통 정보 |
| `captures` | 저장 업무의 캡처 사본 |
| `personal_todos.sqlite3` | 내 할 일·완료 상태·담을 당시 원문·분석 연결 정보 |
| `analysis_cache.sqlite3` | 분석 재사용 캐시 |
| `settings.json` | 창 설정 |

첨부 문서는 앱 데이터 폴더로 복사하지 않고 원래 경로를 기록합니다. 업무를 삭제해도 캡처함 원본·외부 첨부·별도 내 할 일·분석 캐시는 자동 삭제되지 않습니다. 다른 PC에서 이어 쓸 때 GitHub 코드만 가져와서는 API 키나 로컬 업무 데이터가 복원되지 않습니다.

로컬 보관과 외부 전송 없음은 다릅니다. 이미지/문서 OCR·업무 분석·도식화 요청 시 해당 입력이 OpenAI에 전송되고 비용이 발생합니다. TXT/HWPX 읽기 자체는 로컬 처리지만 이후 분석은 API를 사용합니다. 입력을 자동 익명화하지 않으므로 학교의 외부 AI·개인정보 처리 기준을 확인하세요.

학부모 초안의 일부 내부 업무 문장과 휴대전화·이메일·식별번호 형태를 걸러내지만 모든 개인정보를 제거하는 기능은 아닙니다. 이 필터는 생성 결과에 적용되며 API 전송 전 비식별화가 아닙니다. 자동 발송하지 않습니다. API 키·실물 공문·업무 DB는 저장소에 올리지 마세요.

## 검증과 업데이트 적용

2026-09-17 문맥·근거 개선에서 자동 테스트 157개와 오프라인 저장·재열기 시나리오를 확인했습니다. 실제 API 합성 공문 시험 및 이전 날짜·표 검증의 상세 결과는 [VALIDATION.md](VALIDATION.md)에 있습니다. 모든 문서·PC에서의 정확도 보장은 아닙니다.

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -q
.\.venv\Scripts\python.exe -m pip check
.\.venv\Scripts\python.exe tools/verify_release.py
```

`tools/verify_release.py --live`는 합성 문서로 기본 유료 API 3회, 내부 분석 재검토 시 최대 4회 호출합니다.
`tools/verify_date_tables.py "테스트.hwpx"`는 로컬 파일만 검사합니다. 여기에 `--live`를 붙이면 별도 합성 표로 유료 API 2~3회를 호출하며 해당 HWPX는 전송하지 않습니다.
`tools/verify_context_review.py --live`는 합성 공문 2건과 잘못된 기한 복구를 실제 API 3~5회로 시험합니다. `--case 1`, `--case 2`, `--case repair`로 개별 실행할 수 있습니다.
`tools/benchmark_ocr.py`는 로컬 OCR 비교 도구이고 `--cloud` 옵션은 유료 API를 사용합니다.

날짜·표 개선을 적용하려면 앱 재시작 후 파일을 다시 불러오거나 캡처를 재OCR하고 결과를 다시 생성하세요. 기존 저장 업무와 내 할 일은 자동 수정하지 않습니다.

- `services/source_contract.py`, `analysis_review.py`: 원문 좌표 기반 인용·문제 항목의 제한적 재검토

- `services/diagram_service.py`: 업무 도식 이미지 생성
- `tests/`, `tools/`: 회귀 테스트·재현 및 비교 도구
