Ssokly 0.1.0 - Windows x64

Ssokly.exe를 실행하세요. Python 설치나 개인 API 키 입력은 필요하지 않습니다.
설치 없이 사용할 때는 _internal과 ai-server.json을 포함한 폴더 전체를 보관하세요.
보관함 아래의 ? 사용 설명서 또는 F1에서 전체 사용법을 확인하세요.
새 사용자 환경에서는 캡처·문서·휴지통이 비어 있는 상태로 시작합니다.
기존 사용자의 자료는 실행파일 폴더 밖에 저장되므로 업데이트 후에도 유지됩니다.
OCR·AI 정리에는 인터넷 연결이 필요합니다.
업무 실행 → 이미지로 만들기에서 확인한 결과를 PNG로 만들 수 있습니다.
생성 이미지는 자동 보관되지 않으므로 창을 닫기 전에 PNG 저장을 누르세요.
앱을 제거해도 캡처와 문서 데이터는 삭제하지 않습니다.
AI 결과의 담당·날짜·조건은 원문과 대조하세요.

Run Ssokly.exe. Python and an OpenAI API key are not required.
Keep the entire folder together, including _internal and ai-server.json.
AI reading and organization require internet access to the configured relay.

User data: %LOCALAPPDATA%\Ssokly
Captured images: Desktop\ssokly by default, or the selected capture folder.
Back up BOTH locations with the app closed. Uninstall does not delete them.

AI output can be inaccurate. Compare dates, actors and conditions with the source.
Use only a trusted distribution source. Check Digital Signatures in the EXE
file properties for the publisher; unsigned developer builds have no signature.
